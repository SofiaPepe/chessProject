# Analysis 2

`analysis_2` is the official analysis pipeline for the current paper.

Input database:

`data/FINAL_DATABASE_RECALCULATED_MINEFIELD.xlsx`

Input sheet:

`Foglio1`

Run from the repository root:

```powershell
python analysis_2\run_all.py
```

Everything generated by this pipeline is stored in `analysis_2/output/`.
The archived legacy `analysis/` tree and archived exploratory `output/` tree
are not needed for the paper rerun.

## Database Provenance

The input database was created from the original database and raw Minefield
files now stored in:

`archive/database_sources_and_audits/`

The archived Minefield scoring code is:

`archive/legacy_analysis/analysis/minefield_scoring/scoring.py`

The database keeps the original 104-column schema. Only these four columns can
contain recalculated Minefield route-efficiency values:

- `PLANNING_PERC_PRE`
- `PLANNING_PERC_POST`
- `PWM_PERC_PRE`
- `PWM_PERC_POST`

For these columns, raw recalculated values are used when available; otherwise
the historical value is retained. All other historical columns remain
unchanged.

The full best-available Minefield database is archived at:

`archive/database_sources_and_audits/FINAL_DATABASE_MINEFIELD_FULL_BEST_AVAILABLE.xlsx`

It is an audit file only and is not used by `analysis_2`.

## Pipeline Stages

1. `prepare_data.py`: loads the final database, normalizes known column-name
   variants, creates group labels, ABAS/BRIEF totals, Minefield composites, and
   log-transformed time variables.
2. `descriptives.py`: writes descriptive statistics and missingness summaries.
3. `baseline.py`: checks baseline group balance.
4. `pre_age_sex.py`: runs Welch t-tests on cognitive/Minefield PRE measures
   and baseline ABAS/BRIEF questionnaire measures for sex and age differences,
   with Benjamini-Hochberg FDR correction.
5. `correlations.py`: computes Pearson and Spearman correlations with FDR
   correction.
6. `training_effect.py`: tests PRE-to-POST training effects with age-adjusted
   linear models in long format. For each outcome, the primary model is
   `score ~ time * group + age`, with standard errors clustered by participant
   to account for repeated PRE/POST observations. The time-by-group term tests
   whether change differs between the experimental and control groups. The
   module also writes within-group tests, change-score comparisons, and plots.
7. `effectiveness.py`: computes treatment-effectiveness scores for outcomes
   with confirmed theoretical bounds, plus group comparisons and age-adjusted
   comparisons.
8. `predictors.py`: tests ABAS-II and BRIEF-2 predictors of PRE cognitive
   outcomes with age-adjusted standardized linear models
   (`PRE outcome_z ~ questionnaire predictor_z + age_z`). It also keeps the
   exploratory treatment-effectiveness predictor and moderation models in the
   same workbook for audit.
9. `pca_analysis.py`: performs pooled PRE/POST PCA for Minefield domains using
   standardized features and predefined missingness/imputation rules.
10. `run_all.py`: rebuilds `analysis_2/output/`, updates
    `analysis_2/analysis_summary.md`, and writes
    `analysis_2/output/run_manifest.xlsx`.
