# Analysis 2

Independent end-to-end analysis using:

`data/FINAL_DATABASE_RECALCULATED_MINEFIELD.xlsx`

Run from the repository root:

```powershell
python analysis_2\run_all.py
```

Everything generated by this pipeline is stored in `analysis_2/output/`; the
original `analysis/` and `output/` trees are not modified.

Stages:

1. prepared analysis dataset and PRE/POST dictionary;
2. descriptives and missingness;
3. baseline group checks;
4. age and sex tests across PRE measures, adjusted for group and corrected with FDR;
5. Pearson and Spearman correlations with FDR;
6. robust group x time tests (between-group comparison of PRE-to-POST change),
   within-group tests, change-score tests, and covariate-adjusted ANCOVA models;
7. bounded treatment-effectiveness analysis;
8. predictor and moderation models;
9. pooled PRE/POST PCA for each Minefield domain.

The database retains the original schema and values. Only Planning and
WM-Planning route-efficiency percentages are replaced by recalculated values
when raw data are available. Planning composites are the mean of normalized
original accuracy (`accuracy / 16 * 100`) and the recalculated route-efficiency
percentage. Both components are required.
