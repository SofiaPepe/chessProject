# References

`references.bib` contains the bibliographic records used in the Methods and
statistical-analysis sections. Instrument and procedure descriptions were
adapted from `articles_and_documents/chess_scientific_article.qmd`.

Reporting resources:

- STROBE cross-sectional reporting checklist: https://www.equator-network.org/reporting-guidelines/strobe/
- SAMPL statistical reporting guidance: https://www.equator-network.org/reporting-guidelines/sampl/

This directory intentionally contains citations and links only. Proprietary
test manuals and copyrighted PDFs are not copied into the project.
